# 任务抢占工具 v2.0

高速轮询 + 并发认领 + 双线路切换 + 关键词记忆下拉 + 成功提示音 + 防休眠

---

## 快速开始

### 1. 安装 Python（如已安装可跳过）

下载 Python 3.8+：<https://python.org/downloads>

> Windows 安装时勾选 **"Add Python to PATH"**

### 2. 安装依赖

在终端 / 命令提示符中运行：

```bash
pip install aiohttp
```

### 3. 运行脚本

**方法 A — 双击运行（Windows）**

直接双击 `task_claimer.py`，选择"使用 Python 打开"即可。

**方法 B — 命令行运行（Windows / macOS / Linux）**

```bash
python task_claimer.py
# 或
python3 task_claimer.py
```

## 使用说明

脚本启动后会显示 GUI 窗口，分两个标签页：

### 顶部操作栏

| 控件 | 说明 |
|------|------|
| **线路** | 下拉选择线路1 / 线路2（对应两个 Base URL） |
| **目标关键词** | 下拉输入，历史词自动保存，最多记忆 40 条；留空表示匹配任意任务 |
| **▶ 开始** | 启动轮询 |
| **■ 停止** | 停止轮询 |

### 设置页（重要，首次使用必填）

| 字段 | 说明 | 示例 |
|------|------|------|
| 线路1 / 线路2 地址 | 接口域名（不含路径） | `https://api.example.com` |
| 列表接口路径 | list API 的路径 | `/api/task/list` |
| 认领接口路径 | claim/receive API 路径 | `/api/task/receive` |
| Cookie | 登录 Cookie | `session=xxx; token=yyy` |
| 额外请求头 | 其他请求头（JSON） | `{"Authorization":"******"}` |
| 列表请求体 | POST 时的 body（留空=GET） | `{"type":1}` |
| 任务数组路径 | 响应 JSON 中任务列表的路径 | `data.list` |
| 任务 ID 字段名 | 任务对象中的 ID 字段 | `taskId` |
| 任务名称字段名 | 任务对象中的名称字段 | `taskName` |
| 余量字段名 | 剩余数量字段 | `remain` |
| 认领请求体模板 | claim POST body（`{id}` 替换为任务ID） | `{"taskId":"{id}"}` |
| 并发数 | 每轮并发认领请求数 | `6` |
| 轮询间隔 | 两次 list 查询间隔（秒） | `0.3` |
| 认领连接/读取超时 | 认领请求超时参数 | `0.3` / `0.8` |
| 抢占窗口 | 发现目标后持续抢占的时长（毫秒） | `800` |
| 防休眠 | 运行中阻止系统休眠 | ✓ |
| 成功提示音 | 抢到任务后发出三声提示音 | ✓ |

> 设置修改后点击"**保存设置**"，配置自动保存到桌面 `.task_claimer_cfg.json`。

### 日志颜色说明

- 🟢 绿色：认领成功
- 🔵 蓝色：发现目标 / 开始抢占
- 🟡 黄色：超时 / 警告
- 🔴 红色：认领失败

## 工作原理

```
轮询器 (poller)          认领器 (claimer)
─────────────────        ──────────────────────────
持续调用 list API  ─队列─▶  收到信号后在窗口内
发现关键词命中          ×N 并发并行发送 claim 请求
立即写入队列             任一成功 → 停止 → 提示音
                          窗口到期 → 等待下次目标
```

- **查询与认领完全解耦**，查询超时不影响抢占速度
- 认领采用 **短超时 + 随机抖动重试**，避免连接复用到半开连接
- **并发数建议 4~8**，过高会触发服务端限流

## 常见问题

**Q: 运行后弹出"缺少依赖"对话框**  
A: 运行 `pip install aiohttp` 后重试。

**Q: 认领接口一直返回"no task to receive"**  
A: 到达服务端时任务已被抢走，可以尝试减小"轮询间隔"和"认领连接超时"。

**Q: 频繁查询超时**  
A: 检查 Cookie 是否过期，或稍微增大"轮询间隔"避免被服务端限速。

**Q: macOS 无提示音**  
A: 需要系统安装 `afplay`（macOS 自带），或关闭"成功提示音"选项。
